# 3 Days Battle Plan

## Rasio Fokus

```txt
Day 1: Web Exploit 70%, Forensic 20%, Binary 10%
Day 2: Forensic 45%, Web 30%, Binary 25%
Day 3: Simulasi 5 jam + perbaikan catatan/tools
```

## Day 1 — Web Exploit

Target: kamu bisa membuka soal web dan langsung tahu harus mengecek apa.

Wajib latihan:

```txt
SQLi/login bypass        5 soal
LFI/path traversal       3 soal
Command injection        3 soal
IDOR/API/JWT/SSRF        3 soal
```

Output hari 1:

```txt
[ ] Burp nyaman dipakai
[ ] Payload web masuk catatan
[ ] Bisa baca request/response dengan cepat
[ ] Bisa membedakan SQLi, LFI, IDOR, SSRF dari gejala awal
```

## Day 2 — Forensic + Binary

Forensic drill:

```txt
file/image triage        2 soal
stego image              2 soal
pcap HTTP/DNS/TCP        2 soal
log analysis             1 soal
```

Binary drill:

```txt
strings/reverse simple   2 soal
ret2win                  2 soal
buffer overflow offset   1 soal
format string leak       1 soal
```

## Day 3 — Simulasi Lomba

Jangan belajar topik baru berat. Pakai simulasi 5 jam:

```txt
00:00-00:30  triage semua soal
00:30-02:00  Web + Forensic easy
02:00-03:30  Web medium + Forensic medium
03:30-04:30  Binary basic
04:30-05:00  balik ke soal hampir selesai + rapikan notes
```
