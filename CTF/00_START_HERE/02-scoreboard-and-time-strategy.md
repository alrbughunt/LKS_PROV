# Scoreboard and Time Strategy

## Prioritas Solve

```txt
1. Web easy yang familiar
2. Forensic easy yang bisa dichecklist cepat
3. Web medium dengan clue jelas
4. Forensic medium dari pcap/log/stego
5. Binary strings/ret2win/basic overflow
6. Binary berat terakhir
```

## Cara Membaca Soal

Beri label cepat:

```txt
FAST    = sudah tahu jalur solve
MEDIUM  = butuh eksplorasi 15–30 menit
HARD    = belum tahu, tunda
```

## Kapan Skip?

Skip jika:

- 10 menit pertama belum tahu attack surface.
- 25–30 menit tidak ada leak/clue baru.
- Tool error dan belum bisa diperbaiki cepat.
- Butuh teknik yang belum pernah kamu latih.

## Kapan Balik?

Balik jika:

- Sudah punya clue dari soal lain.
- Tinggal decode/extract/automate.
- Tinggal cari offset/alamat fungsi.
- Tinggal menulis payload final.
